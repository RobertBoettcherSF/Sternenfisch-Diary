# 2026-10-20 — Diary Sim

**Date:** 2026-10-20

**Title:** Diary Sim

**Tags:** ada, simulation

## Note

Diary Sim is published as a public Ada 2022 repository. Four beings (the wesen) write a diary line per tick, teach and coin words, and grow a shared vocabulary. Each run replays its saved history from the seed and checks it byte for byte. `make test` runs the unit tests and a smoke test; GitHub Actions builds with GNAT 12 and 14.
