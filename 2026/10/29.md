# 2026-10-29 — Spectrum analyzer and Colony4X

**Date:** 2026-10-29

**Title:** Spectrum analyzer and Colony4X

**Tags:** ada, spark, wasm, game

## Spectrum analyzer

An Ada spectrum analyzer in the browser. The transform runs in WebAssembly; JavaScript asks for the spectrum, the waterfall, the markers, and the carrier edges, then paints them. The opening demo is a short 8 kHz take with mains, harmonics, and a ripple-control telegram. A 16-bit PCM WAV can be loaded. The same day the core is proved to SPARK Silver and the page is published.

## Colony4X

Colony4X opens as v0.6, a clean-room browser 4X about colonising an alien planet. Names, text, and graphics are original. It plays on GitHub Pages, and `index.html` also opens offline. The same day adds full social policies (v0.7) and city morale and unrest (v0.8).
