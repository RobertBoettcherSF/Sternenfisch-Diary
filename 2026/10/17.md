**Date:** 2026-10-17

**Title:** Logistic Manager

**Tags:** logistics

## Note

Logistic Manager v0.2 is a demo ride and transport prototype for Benin City, in the style of Bolt and inDrive. One HTML, CSS, and JavaScript app covers customer and driver: car, group bus, dispatch rider, truck, and a private-jet charter request. A small Node server can sync two phones; without it, simulated drivers keep the demo moving. The offline file is `dist/swift-drive.html`. The commit reports tests 64/64.
