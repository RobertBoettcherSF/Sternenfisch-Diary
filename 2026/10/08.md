# 2026-10-08 — Folder migration and proof index

**Date:** 2026-10-08

**Title:** Folder migration and proof index

**Tags:** ada, spark, algorithms

## Per-folder migration

The monorepo finishes the move into one folder per algorithm. Loose package sources and project files go into the folder that builds them, including the `.gpr` files a makefile names with `-P`. Shared loose files are copied into each folder that uses them, so a folder stands alone.

## SPARK proof index

The same day adds a root proof index. `make proof-index` writes `PROOFS.md` and `PROOFS.csv` from the build and GNATprove records. SPARK-level folders without `SPARK_Mode` are marked skipped. The headline counts are generated, not typed by hand.
