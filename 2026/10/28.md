# 2026-10-28 — Murmuration

**Date:** 2026-10-28

**Title:** Murmuration

**Tags:** ada, spark, wasm

## Note

A starling murmuration in Ada/SPARK: Reynolds' boids, with separation, alignment, and cohesion. The simulation is proved with GNATprove, compiled to WebAssembly, and drawn in the browser. JavaScript only paints the birds. The first public build is v0.1, with a live page the same day. The world is a torus and the arithmetic is fixed-point, so the bounds stay exact.
