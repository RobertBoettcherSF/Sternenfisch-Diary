# 2026-11-19 — poncelet

**Date:** 2026-11-19

**Title:** poncelet

**Tags:** ada, game

## Note

Poncelet is a design draft for a commercial desktop game engine and editor, with the core planned in plain Ada. The draft names three first-release pillars beside a 2D and 3D aim: projective geometry, fractals, and density. Games would ship on Steam, and the editor is described as the first product.

The repository holds the design document, the implementation plan, and a name check. It is a design draft. There is no code yet.
