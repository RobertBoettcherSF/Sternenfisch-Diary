# 2026-11-03 — Irlmaier simulation

**Date:** 2026-11-03

**Title:** Irlmaier simulation

**Tags:** ada, wasm

## Note

A small public simulation after Conrad Adlmaier, "Blick in die Zukunft" (1950–1961). The picture on the page is Sassoferrato's "Die Jungfrau im Gebet", public domain. The map is Ada compiled to WebAssembly: a North Sea chart in v0.2, then an impact point and a phone layout in v0.3. GitHub Pages hosts the page.
