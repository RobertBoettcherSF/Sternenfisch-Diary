## Note

wish-app-demo publishes the synthetic Wish App v0.3.0 interface so it can be opened in a browser. The page is a five-tab shell with a visible version, a Debug control, decorative Devanagari rain, tap sounds, and English or German labels. A wish can be kept in that browser as text, a theme, and an optional priority. Settings can prepare a backup file of those wishes and import one after a preview.

The file is not encrypted, and nothing is uploaded. On this shared public page the examples should stay fictional. Storage here is not a private account, and the browser can remove it. This build contains no personal wishes, names, media, or accounts.
